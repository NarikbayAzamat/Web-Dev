# Python CLI Task Manager

## Description
This project is a simple command-line task manager written in Python.

## Features
- Show tasks
- Add task
- Complete task
- Delete task
- Save tasks to JSON file

## Project Structure
- `models.py` - contains the `Task` class
- `storage.py` - handles loading and saving tasks in `data.json`
- `main.py` - main menu and program logic
- `data.json` - stores tasks
- `README.md` - project description

## How to Run
Run the program with:

```bash
python main.py
